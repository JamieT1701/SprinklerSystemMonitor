# Superseded build instructions

Do not assemble from this older revision. The complete historical text is preserved in Git history.

Use the [authoritative two-terminal build guide](./BUILD-GUIDE.md) or [interactive bench tutorial](./index.html). The current design has one factory RJ45, exactly two 3-position sensor terminal blocks on Board B, two 50 x 70 mm perfboards, an onboard 4.7k temperature pull-up, and a second 4.7k in the pressure divider.

The earlier generated assembly pictures are withdrawn as wiring references. Read the [engineering review](./ENGINEERING-REVIEW.md) for what was checked and what remains physically unverified.
